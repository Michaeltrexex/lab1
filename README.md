# Telegram Task Reminder Bot 📲

Простой Telegram-бот для напоминаний о задачах, подключенный к MySQL.

## 🚀 Возможности

- Авторизация (логин/пароль)
- Выбор задач из базы
- Установка напоминаний через X минут
- Напоминания приходят автоматически
